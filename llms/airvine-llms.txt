## API surface

Airvine publishes **no public API**. There is no developer portal, no API reference, no
OpenAPI/AsyncAPI/GraphQL document, no SDK on any public package registry, no public MCP
server and no A2A agent card; developer.airvine.com, docs.airvine.com and api.airvine.com
do not resolve. The devices themselves expose a management surface: the public WaveTunnel
User Manual and Configuration Guide lists a Web GUI, mobile app, command-line interface,
"Open API" and SNMP interface, and the WaveCore Configuration Guide describes a per-device
"RESTAPI Authentication Key" for external remote-management connections. Both manuals refer
readers to separate "API/SNMP documents" that are not published on the public Technical
Documentation page, so the contract is customer-only and nothing here is derived from it.
